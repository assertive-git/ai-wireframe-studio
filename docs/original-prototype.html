AIへ伝える参照ポイント

構成を参考ページ全体をコピーせず、セクションの順番と情報量を参照します。
特定箇所を参考「FV」「賞の見せ方」など、採用する箇所だけを指定できます。
参考のみ画像や固有コピーは転用せず、デザイン意図だけをAIへ渡します。
プログラマ打ち合わせ用メモ
  1. 案件単位の永続化
    構想、素材、参考URL、チャット履歴、現在のHTML/CSS、バージョンを一体で保持。
  2. 差分修正を基本にする
    AIは毎回全生成せず、対象セクションと変更内容を特定して反映。
  3. プレビューとチャットを同時表示
    見ながら指示できることが、このUIの中心価値。
  4. 直接編集は二段階
    本文のインライン編集と、HTML/CSSコード編集を用意。
  5. 素材の権利区分
    「正式利用可」「仮置き」「参考のみ」を素材ごとに管理。
  6. バージョン管理
    AI反映前後の差分確認、取り消し、過去版復元が必要。
MVPではドラッグ＆ドロップ式の自由レイアウト編集より、チャット修正・テキスト編集・コード編集を優先。
